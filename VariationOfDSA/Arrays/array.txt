Q1. Problem Statement
Given an array (can contain positive, negative, and zero values), we need to find the maximum subarray sum.

            arr = [-2, 1, -3, 4, -1, 2, 1, -5, 4]                                 Output = 6  
                                                  =====>>          (  Explanation: subarray [4, -1, 2, 1] has the largest sum = 6)

Optimal Approach — Kadane’s Algorithm (O(n) time)
So, majorly three steps 
 Step 1  ==>   Traverse once, keep adding the current element to a running sum.
 Step 2  ==>   If the running sum becomes negative, reset it to 0 (because starting fresh is better).
 Step 3  ==>   Keep track of the maximum sum seen so far.
