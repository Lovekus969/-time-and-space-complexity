Linked Lists Definition:
A collection of nodes where each node contains data and a pointer to the next node (and possibly the previous one in a doubly linked list).
                                Advantage and some disadvantages of the linklist data structure 
           Advantages                                                                              Disadvantages
          Dynamic size (no fixed memory block like arrays)                                 No direct indexing (O(n) to access)
          Easy insertion/deletion at head/middle without shifting elements                 Extra memory for pointers
                                                                                            More complex to implement than arrays

Detect a Cycle in a Linked List (Floyd’s Tortoise & Hare)
            Intuition
                        slow pointer moves 1 step at a time
                        fast pointer moves 2 steps at a time
                        If there’s no cycle, fast will eventually hit null and we return false.
                        If there is a cycle, fast will eventually “lap” slow and they’ll meet inside the cycle.

Find the Middle of a Linked List
          Intuition (Two-pointer method):

                        slow pointer moves 1 step
                        fast pointer moves 2 steps
                        When fast reaches the end, slow is in the middle. it’s basically O(n) time and O(1) space,
                        and feels like we’re sneakily cutting the list in half without ever knowing its length beforehand.

Palindrome Linked List 
                  Logic:
                        Find middle of list (Floyd’s slow/fast trick — same as in cycle detection but we stop at middle).
                        Reverse the second half of the linked list in-place.
                        Compare the first half & second half node by node.
                        (Optional) Restore list to original form.
